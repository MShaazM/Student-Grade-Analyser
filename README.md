# Student Grade & Performance Analyzer

A lightweight Python application designed to analyze student performance metrics, calculate GPA, and render visual data distribution charts.

## 🚀 Features
- Calculates average percentage and GPA metrics from raw subject data.
- Generates automated visual performance bar charts using `Matplotlib`.
- Integrates structured dictionary formats for clean, extensible data flow.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Matplotlib
